# Extension Icons

This directory contains the extension icons.

For Phase 1, we're using placeholder text files. In production, these should be replaced with actual PNG images.

## Required Icons

- `icon-16.png` - 16x16 pixels (toolbar)
- `icon-32.png` - 32x32 pixels (Windows)
- `icon-48.png` - 48x48 pixels (extension management page)
- `icon-128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

You can create icons using:
1. Online tools like https://www.canva.com or https://www.figma.com
2. Image editors like Photoshop, GIMP, or Photopea
3. Icon generators like https://icon.kitchen

## Design Guidelines

- Use a consistent color scheme (current: purple/blue gradient #667eea to #764ba2)
- Include a recognizable symbol (target, chart, score badge)
- Ensure visibility on both light and dark backgrounds
- Keep it simple and professional
